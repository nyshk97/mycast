# mycast 初期実装（Raycast 代替の自分用ランチャー）

## 概要・やりたいこと

Raycast のうち実際に使っている 3 機能だけを持つ、自分用の Mac アプリ `mycast` を作り、Raycast を置き換える。

- アプリ起動（エイリアス付き）
- クリップボード履歴の呼び出し
- 絵文字ピッカー

他の自作アプリ（keyrc・translate 等）と同じく、`nyshk97/tap` の cask として Brewfile からインストールでき、Sparkle でアプリ内アップデートできるようにする。
Raycast で行っている設定は**固定の既定値**として焼き込み、設定画面は作らない。

## 前提・わかっていること

### 技術・配布（keyrc の構成を流用）
- Swift + AppKit（パネルの中身は SwiftUI 可）+ XcodeGen。`project.yml` が真実の源で、`.xcodeproj` は生成物
- 最も近い雛形は `~/keyrc`（メニューバー常駐・`LSUIElement: true`・Sparkle 自動チェック ON・`mise run release` で notarize → GitHub Release → `nyshk97/homebrew-tap` の cask 更新まで一気通貫）。`scripts/`（preflight / release / notarize / changelog.py / gen-signing-xcconfig.sh / make-release-zip.sh）と `.mise.toml` をコピー元にする
- 作法は `~/Library/CloudStorage/Dropbox/dotfiles/.claude/references/personal-mac-apps.md` と `swift-projects.md` に従う（dev/常用の分離、署名 ID の自動解決、バージョン一元管理、`docs/CHANGELOG.md` の `[Unreleased]` ゲート、dev 版に `SUFeedURL` を入れない等）
- 配信先は keyrc と同じく「本体 repo（public）の GitHub Release」に置く。feed は `https://github.com/nyshk97/mycast/releases/latest/download/appcast.xml`
- bundle id: 常用 `io.github.nyshk97.mycast` / dev `io.github.nyshk97.mycast.dev`（表示名 `mycast Dev`、アイコンに DEV リボン）
- Sparkle の EdDSA 鍵は `--account mycast` で新規作成し、`Dropbox/secrets/` にバックアップする
- Brewfile には `cask 'nyshk97/tap/mycast'` を「自作アプリ」ブロックにアルファベット順で追加する

### Raycast から引き継ぐ固定の挙動（実機の `defaults read com.raycast.macos` で確認済み）
| Raycast の設定 | mycast の固定挙動 |
|---|---|
| Hotkey `Control-37`（Ctrl+L） | 常用版のランチャー呼び出しは ⌃L |
| Window Mode = compact | 開いた直後は検索欄だけ。入力すると候補リストが下に伸びる |
| Auto-switch Input Source = ABC（`com.apple.keylayout.ABC`） | パネル表示時に入力ソースを ABC に切り替え、閉じたら表示前の入力ソースに戻す（TIS API。切り替え直後の 1 打目対策として、ルート検索の入力欄では IME を無効化する。クリップボード履歴・絵文字では日本語で検索できるよう無効化しない） |
| Pop to Root Search = Immediately | 開くたびに入力は空・ルート検索に戻る |
| Show Raycast on = Screen containing mouse | 開いたときにカーソルのある画面の上 1/5 あたり（上端を固定）に中央寄せ。閉じるまで画面は変えない |
| Clipboard History のエイリアス `c` | ルート検索で `c` → Enter で履歴を開く |
| Search Emoji & Symbols のエイリアス `e` と ⌃⌘Space | ルート検索で `e` → Enter、または ⌃⌘Space で絵文字の検索を直接開く |

- Raycast の Ask AI（Tab）・拡張・システムコマンド（Hide All Apps 等）・ファイル検索・計算機は使っていないので作らない
- エイリアスはキーワードに完全一致したら、その項目を候補の 1 位にする（Raycast と同じ）

### ルート検索（アプリ起動）
- 対象: `/Applications`・`/System/Applications`・`/System/Applications/Utilities`・`~/Applications` の `.app`、およびシステム設定の各パネル（`/System/Library/ExtensionKit/Extensions` 配下の設定用 `.appex` から一覧を作り、`x-apple.systempreferences:` の URL で開く）。載せるのは `allowsXAppleSystemPreferencesURLScheme` を宣言した appex だけ。全件を開く確認はせず、抜き取りで開かないものが出たら固定表で補う
- アプリは `NSMetadataQuery`（`kMDItemContentType == com.apple.application-bundle`、上記ディレクトリに限定）で集め、サブフォルダ（`/Applications/Utilities`・ベンダーフォルダ・Chrome Apps 等）も拾う。変更も同じクエリの更新通知で反映する。結果は DB にキャッシュし、0 件（インデックス再構築中など）ならディレクトリ走査にフォールバックする。パスに `.app/` を 2 回以上含むもの（アプリ内のヘルパー）は除外する
- 表示名（ローカライズ名）と英語名の両方で、あいまい一致（先頭一致・単語頭一致・部分一致の順に加点）＋ frecency（起動回数に最終使用日時で時間減衰をかける）で並べる
- アプリ用のエイリアスは付けない（ユーザー判断）。エイリアスは組み込みコマンドの `c` / `e` だけ。日本語名のアプリも英語名・ローマ字化した表示名で引ける

### クリップボード履歴
- 記録するもの: テキスト・画像・ファイル（Finder でコピーしたファイル参照）
- 保存期間は 3 か月。起動時と 1 日ごとに古いものを消す
- `NSPasteboard.general.changeCount` を 0.5 秒ごとにポーリングして記録する。自分が貼り付けのために書いた直後の `changeCount` は記録しない
- `org.nspasteboard.ConcealedType` / `TransientType` / `AutoGeneratedType` が付いたコピー（Bitwarden 等）は記録しない
- 同じ内容をもう一度コピーしたら、新しく足さずに先頭へ移す
- 操作: Enter で前面アプリに貼り付け（順序を固定: パネルを閉じる（この経路では閉じる処理に元アプリへの復帰を含めない）→ 入力ソースを復元 → 元のアプリを明示的に 1 回だけ前面化し完了を待つ → ペーストボードに書く → 押下中の修飾キーが混ざらないよう独立したイベントソースで ⌘V を合成）、⌘Enter はコピーだけしてパネルを閉じる（絵文字も同じ）。検索欄で絞り込め、右側に内容のプレビュー（画像はサムネイル）を出す
- ⌘V の合成にはアクセシビリティ許可が要る。許可が無いとき、または貼り付け直前に Secure Event Input が有効なとき（`IsSecureEventInputEnabled()`）は「コピーだけ」に落として、その旨を表示する
- 履歴は平文の SQLite で持つ（暗号化はしない。FileVault 前提の個人機で、Raycast 側も同じ情報を端末内に持っていた。今回の範囲に入れない。1回目で決定）
- 保存先: `~/Library/Application Support/mycast/`（SQLite + 画像ファイル。起動回数・最近使った絵文字も同じ DB に置く）。履歴は壊れても致命的ではないが、dev の実装途中のコードが常用の履歴を壊さないよう、dev は `mycast-dev/` に分ける
- Raycast の履歴は暗号化されているため引き継がない（移行した時点から記録し直す）

### 絵文字ピッカー
- 自前で実装する。英語名・日本語のキーワードで検索して、Enter で前面アプリに貼り付け（⌘Enter でコピーだけ）。貼り付けはクリップボード履歴と共通の処理（順序・縮退とも同じ）を使う
- データはリポジトリに同梱する（Unicode CLDR の annotations 英語・日本語から生成した JSON をコミットする。生成スクリプトも置く）
- 最近使ったものを上に出す。グリッド表示で矢印キーで移動できる
- 肌の色バリエーションは出さず、基本のコードポイントだけを候補にする（今回の範囲に入れない。1回目で決定）

### UI・常駐
- Dock には出さない（`LSUIElement`）。メニューバーに小さなアイコンを置き、メニューは「About / アップデートを確認 / 終了」だけ
- フォーカスは Raycast と同じモデルに一本化する: ホットキーで前面アプリを記憶 → 自アプリをアクティブ化 → key になれる `NSPanel` を表示 → 閉じるときに記憶したアプリをアクティブ化して戻す（戻す条件は次項）
- パネルは `NSVisualEffectView`（HUD 系のダーク半透明）、level は `.floating` 以上、`.canJoinAllSpaces` ＋ `.fullScreenAuxiliary`（フルスクリーンのアプリ上でも出る）。Esc かパネル外のクリック（＝パネルが key でなくなる）で閉じる。元のアプリへ戻すのは Esc / ホットキー再押下 / 項目の実行で閉じたときだけ（他アプリをクリックして閉じたときは、そのアプリを前面のままにする）
- ログイン時に自動起動する（`SMAppService.mainApp.register()`、常用版のみ）
- Sparkle の自動チェックは ON（常駐して存在を忘れる種類のアプリのため）
- バージョン表示の導線: パネル下端（またはメニューバーのメニュー）に小さく `v0.x.y` ＋ About パネル

### Raycast との並行期間
- dev 版は別のホットキー（⌃⌥L / ⌃⌥⌘Space）で動かし、Raycast と並行させる
- 常用版を入れた時点で Raycast を止めてアンインストールする。ホットキー登録（Carbon `RegisterEventHotKey`）に失敗したら、起動時は NSAlert で知らせ、以後はメニューバーのアイコン表示で気づけるようにする
- ⌃⌘Space は macOS 標準の文字ビューアとも重なる。Raycast と同様にアプリ側のグローバルホットキーで先に取れるかを実機で確認する（取れなければシステム設定のキーボードショートカットで標準側を外す）
